Abra pelo servidor local, não pelo arquivo

Você abriu esta página com file:// (duplo clique no index.html). Navegadores modernos bloqueiam módulos JavaScript nesse modo.

No terminal, dentro da pasta Projeto/sanepar-3d:

npm install
npm run dev

Depois abra o endereço que o Vite mostrar (em geral http://127.0.0.1:5173).

Visualização 3D indisponível

Este navegador não disponibilizou WebGL, ou o contexto gráfico foi perdido. A cena 3D não pode ser exibida, mas a simulação, os cartões executivos e os contadores continuam funcionando.
